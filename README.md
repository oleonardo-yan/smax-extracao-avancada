# Smax - Extração Avançada

Userscript (Tampermonkey) para extração avançada de dados na plataforma Smax.

## Instalação

1. Instale a extensão [Tampermonkey](https://www.tampermonkey.net/) no navegador.
2. Abra o arquivo [`smax-extracao-avancada.user.js`](./smax-extracao-avancada.user.js) e clique em "Raw" (ou use o Tampermonkey para importar diretamente pela URL raw do GitHub).
3. Confirme a instalação no Tampermonkey.

## Desenvolvimento

O script está em `smax-extracao-avancada.user.js`. Ajuste o bloco `@match` no cabeçalho para a URL real do seu ambiente Smax antes de usar.
